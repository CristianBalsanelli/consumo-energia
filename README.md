Calculadora de consumo de aparelhos elétricos
Linguagem: Python
Fórmula usada para cálculo: 
custoKW = 0.75
consumoMensal = (potencia * horasDia * 30)/1000
valorMensal = consumoMensal * custoKW
Instruções para executar o programa: Rode o programa, digite o nome de um aparelho elétrico, digite a sua potência em watts, digite o tempo utilizado em horas por dia, na variavel custoKW informa o valor do KW cobrado pela concessionária de energia elétrica

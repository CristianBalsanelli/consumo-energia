Calculadora de consumo de aparelhos elétricos </br>
Linguagem: Python </br>
Fórmulas usadas para cálculo: </br> 
custoKW = 0.75 </br>
consumoMensal = (potencia * horasDia * 30)/1000 </br>
valorMensal = consumoMensal * custoKW </br>
Instruções para executar o programa: Rode o programa, digite o nome de um aparelho elétrico, </br>
digite a sua potência em watts, digite o tempo utilizado em horas por dia, </br>
na variavel custoKW informe o valor do KW cobrado pela empresa de energia elétrica
